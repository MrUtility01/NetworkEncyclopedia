# معماری استقلال

```
┌─────────────────────┐         اختیاری (LAN)        ┌─────────────────────┐
│  Windows (Host)     │◄────── Sync دو طرفه ───────►│  Android            │
│  Flask + SQLite     │      فقط با دکمه کاربر      │  Room + فهرست محلی  │
│  ۶۳ فصل کامل        │                              │  ۶۳ فصل آفلاین      │
│  بدون نیاز به گوشی  │                              │  بدون نیاز به PC    │
└─────────────────────┘                              └─────────────────────┘
```

## اصل

1. **ویندوز** به‌تنهایی کامل است (وب + دیتابیس + درس‌ها).
2. **اندروید** به‌تنهایی کامل است (فهرست ۶۳ فصل + درس‌ها در Room).
3. **همگام‌سازی** فقط وقتی کاربر بخواهد و هر دو روی یک Wi‑Fi باشند.
4. هیچ‌کدام برای «باز شدن و کار کردن» به دیگری وابسته نیست.

## جریان Sync (اختیاری)

- اندروید → ویندوز: push تغییرات محلی
- ویندوز → اندروید: pull درس‌های به‌روز
- قانون تعارض: Last-Write-Wins
