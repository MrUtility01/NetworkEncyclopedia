# نصب نسخه قابل‌حمل ویندوز — NetworkEncyclopedia

## نیازمندی‌ها
- ویندوز 10/11 نسخه 64 بیتی
- برای اجرای بستهٔ EXE نصب جداگانه Python لازم نیست.
- برای همگام‌سازی LAN دستگاه‌ها باید روی شبکهٔ مورداعتماد باشند.

## راه‌اندازی
1. فایل NetworkEncyclopedia-Windows-x64.zip را از بخش Artifacts اجرای موفق GitHub Actions دریافت و در مسیری قابل‌نوشتن استخراج کن.
2. START_EXE.bat را اجرا کن؛ ورودی توکن در PowerShell به‌صورت محافظت‌شده نمایش داده می‌شود.
3. یک توکن خصوصی و قوی برای همگام‌سازی وارد کن؛ توکن را در مخزن یا گزارش عمومی منتشر نکن.
4. پنجرهٔ سرور را باز نگه دار؛ مرورگر معمولاً با http://127.0.0.1:5050 باز می‌شود.
5. برای همگام‌سازی اندروید در همان Wi-Fi، IP ویندوز را از خروجی سرور یا /api/lan بخوان و در اپ وارد کن.

## امنیت شبکه
- اگر Windows Firewall پرسید، فقط در شبکهٔ Private و مورداعتماد اجازه بده؛ بازکردن Public profile توصیه نمی‌شود.
- برای LAN فقط پورت 5050/TCP و فقط از مبدأهای مورداعتماد را باز کن.
- برنامه را مستقیماً روی اینترنت expose نکن؛ برای دسترسی بیرونی VPN و HTTPS/reverse proxy امن طراحی کن.
- توکن واقعی را در BAT، source code، log یا GitHub ذخیره نکن.
- از دیتابیس محلی و backup آن با مجوزهای مناسب محافظت کن.

## عیب‌یابی
- اگر EXE پیدا نشد، ZIP را کامل استخراج کن و BAT را از همان پوشه اجرا کن.
- اگر پورت 5050 اشغال بود، پیش از اجرا متغیر NETENC_PORT را تنظیم کن.
- اگر مرورگر باز نشد، آدرس لوکال را دستی وارد کن.
- برای خطای startup، پنجره را نبند؛ خروجی را بررسی و بدون secret گزارش کن.
- بسته portable است؛ code-signing در این build تنظیم نشده و ممکن است Windows SmartScreen هشدار فایل ناشناخته نمایش دهد.
